# vykopy-sazava.cz

Web pro výkopové práce minibagrem — Sázava a okolí (okres Benešov, Posázaví).

Aktuálně **placeholder** (holding page). Finální obsah a design se doplní z návrhu
z Claude Design.

## Struktura

- `index.html` — stránka
- `style.css` — styly

Statický web bez závislostí — stačí otevřít `index.html` v prohlížeči.

## Poznámky

- Tajné hodnoty patří do `.env` (je v `.gitignore`, necommituje se).
